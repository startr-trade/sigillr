# v0.1.1

_Released 2026-11-22._

A small fix release after 0.1.0. Nothing in the `sigillr` command changes.

## Fixed

- The README shows the Sigillr logo on crates.io, and its Install section no longer says there is no public release. crates.io keeps each version's README, so the fix shows from this version on.
- The release workflow creates the GitHub release with this page as its notes. For 0.1.0 it looked for the notes under the wrong name, so that GitHub release was created by hand from the same workflow's files. Every dry run now checks the notes exist before a tag is pushed.
